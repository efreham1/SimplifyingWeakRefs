\chapter{Changed Source Code}
\label{app:changed-source-code}

This appendix lists the source files changed to implement the weak-reference processing optimisations evaluated in this thesis. The code shown is from the \texttt{all} configuration variant, which combines all three optimisations (separate discovered lists, dynamic arrays, and the optimised clear path). Each configuration variant is stored under \texttt{patches/<variant>/src/} and overlaid onto the upstream OpenJDK source tree before building.

Files changed in the \texttt{all} variant:
\begin{itemize}
	\item \texttt{patches/all/src/hotspot/share/gc/z/zWeakRefArray.hpp}
	\item \texttt{patches/all/src/hotspot/share/gc/z/zReferenceProcessor.hpp}
	\item \texttt{patches/all/src/hotspot/share/gc/z/zReferenceProcessor.cpp}
\end{itemize}

Common files shared by most ref-proc variants (applied via \texttt{patches/base/}):
\begin{itemize}
	\item \texttt{patches/base/src/hotspot/share/gc/shared/collectedHeap.hpp}
	\item \texttt{patches/base/src/hotspot/share/gc/z/zCollectedHeap.cpp}
	\item \texttt{patches/base/src/hotspot/share/gc/z/zCollectedHeap.hpp}
	\item \texttt{patches/base/src/hotspot/share/gc/z/zGeneration.hpp}
	\item \texttt{patches/base/src/hotspot/share/gc/z/zGeneration.inline.hpp}
	\item \texttt{patches/base/src/hotspot/share/gc/z/zStat.hpp}
	\item \texttt{patches/base/src/hotspot/share/gc/z/zStat.cpp}
	\item \texttt{patches/base/src/hotspot/share/runtime/threads.cpp}
\end{itemize}
